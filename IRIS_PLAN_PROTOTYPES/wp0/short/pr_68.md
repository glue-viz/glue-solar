On macOS the menu bar showed "python" instead of "glue" and in-app text was smaller than the system UI (screenshots below).

- Set `CFBundleName` of the running Python bundle to `glue` through pyobjc before the `QApplication` exists; Qt takes the macOS menu title and the About/Hide/Quit labels from it. New dependency `pyobjc-framework-Cocoa; sys_platform == 'darwin'`; without it the code falls back to today's behaviour. `test_mac_bundle_name` guards it.
- Use the platform default font everywhere instead of subtracting 2 pt on macOS and 1 pt elsewhere (Linux/Windows text grows by 1 pt). `FONT_SIZE = -1` means "track the platform default" and is not persisted.
- Remove the hardcoded font sizes and the `px` tab-title workaround on Qt6; toolbar and list icons follow `PM_ToolBarIconSize` (capped at 24 px).

Based on #69 until it merges. `setApplicationName('glue')` renames the default macOS `QSettings` plist; glue-qt does not use `QSettings` directly.
