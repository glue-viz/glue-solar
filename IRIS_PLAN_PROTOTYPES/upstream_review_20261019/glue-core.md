## Generic features worth upstreaming (glue-core side)

- **Units on axis labels** (#25): small, Profile viewer first; every unit-aware glue user gains.
- **A `Quantity` saver and `DerivedComponent.units` in sessions** (#11, #28): small; needed by any plugin that attaches units.
- **An ECSV exporter**: one `table_exporter('ascii.ecsv', 'ECSV', 'ecsv')` line; keeps datetimes and units where CSV loses both.
- **Data-provided statistics** (`LazyData.compute_statistic`, `_Cube.compute_statistic`): what glue-solar overrides is the API issue #2133 asks for (a dataset answering min/max/percentile cheaply); medium, and it would make the `RawComponent` sampling upstream-shaped.
- **Composite-model fitting in `glue.core.fitters`** (the IRIS fitter's model builder): the core part is a fitter whose `model_cls` composes astropy models with ties and a `settings_widget` hook; medium-large, and glue-qt owns the widget. `set_constraint`'s clear (#16) comes first.
- **Vertical/horizontal marker lines**: astrofrog's #2603 merged 2026-10-21 (d92db05c, in the pending 1.28.0): line layer artists in `glue/viewers/{common,matplotlib}/line_layers.py`. The quicklook's wavelength, time and point lines (`quicklook.py`, `tools.py` overlays) are matplotlib `Line2D`s by design (out of sessions, D39), so there is no port. #2603's `profile/state.py` guard for layers without `attribute` touches neither #15's `_update_priority` nor #23/#48's `_reset_y_limits`, so neither proposed fix conflicts.
- Follow/lock as a Pixel hover mode, Loop's range options, Blink (#670 open since 2015), Hide axes (#2128 open, changes requested), Per-frame limits (`stretch_global`) as a control: glue-qt's, listed by that reviewer.

Cross-project, mentioned once: mpl-scatter-density's 0.5 s resize hold (`SaveSequenceTool` calls `on_release()`, #270) belongs to mpl-scatter-density (ignore the hold while `canvas._is_saving`).
