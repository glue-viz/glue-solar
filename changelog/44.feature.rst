IRIS Level 2 support now browses a whole folder (recursively, pooch caches included) by observation: one row per OBSID and start time with description, pointing and file counts; tick SJI bands, raster spectral windows or co-aligned AIA cutouts to load them, or tick a packed ``*.tar.gz`` download to extract it in place. Available from "Plugins -> IRIS: browse observations…", which also opens the first image in an Image Viewer. Rasters keep the exact per-exposure times, the original detector values and irispy's tabular spatial WCS, and helioprojective coordinates are shown in arcseconds. This replaces the previous one-directory importer and the ``qglue`` parsers.
