Sunpy maps link to IRIS data: "IRIS: link helioprojective coordinates" and the observation browser pair a map's helioprojective longitude and latitude, in degrees, with IRIS's arcsec, while Glue's own WCS autolinking keeps linking maps to each other. Raster regions reach a map whose longitudes run to 360 degrees, and the Pixel point leaves one crosshair when a map is shown over a quicklook panel.
